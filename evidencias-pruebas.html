3. Prestamos

POST

Registrar prestamo (descuenta stock)

201

http://localhost:8080/api/loans

Resta la cantidad al stock del equipo (6 -> 4). loanDate es opcional: si no se envia se usa la fecha de hoy.

Cuerpo enviado
{
  "studentId": "{{anaId}}",
  "equipmentId": "{{portatilId}}",
  "quantity": 2
}
Respuesta
{
  "id": 4,
  "loanDate": "2026-09-19",
  "returnDate": null,
  "quantity": 2,
  "equipment": {
    "code": "PORT-001",
    "id": 8,
    "name": "Portatil Lenovo T14",
    "stock": 4
  },
  "student": {
    "email": "ana.perez@usantoto.edu.co",
    "id": 6,
    "name": "Ana Pérez Gómez",
    "program": "Ingeniería de Sistemas"
  }
}
